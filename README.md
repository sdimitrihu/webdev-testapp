# Αξιολόγηση καθηγητών
Εφαρμογή που επιτρέπει σε φοιτητές να αξιολογούν καθηγητές. Περιλαμβάνει 2 σελίδες

## index.html - Σελίδα επισκέπτη
Ο φοιτητής μπορεί να δει τους διαθέσιμους καθηγητές και να βαθμολογήσει Θετικά ή Αρνητικά τον καθένα.

## admin.html - Σελίδα διαχειριστή
Ο διαχειριστής μπορεί να προσθέτει καθηγητές (ονοματεπώνυμο, email, εργαστήριο) και να τους διαγράφει.
